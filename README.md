# КБЖУ — Telegram Mini App

Личный счётчик калорий и КБЖУ в стиле Apple/iOS. Без сервера: данные хранятся в
**Telegram CloudStorage** (синхронизация между устройствами) с фоллбэком на
localStorage для обычного браузера.

## Возможности
- **Дневник** за день: кольцо прогресса ккал + полоски Б/Ж/У относительно цели.
- **Продукты**: добавляешь название и КБЖУ на 100 г, переиспользуешь.
- **Рецепты**: собираешь блюдо из продуктов с граммовками — КБЖУ считается само.
- **Цель**: дневная норма ккал/белки/жиры/углеводы.

## Стек
Чистый HTML/CSS/JS (ES-модули), **без сборки и без зависимостей**. Системный шрифт
Apple (SF Pro). Деплоится как статика.

```
index.html        каркас + подключение Telegram SDK
styles.css        стили (Apple-минимализм, темизация под Telegram)
src/storage.js    CloudStorage ↔ localStorage
src/nutrition.js  расчёты КБЖУ (чистые функции)
src/state.js      in-memory store + сохранение
src/ui.js         экраны и нижние листы
src/app.js        точка входа
```

## Локальный запуск
```bash
cd "путь/к/kkal"
python3 -m http.server 8765
# открыть http://localhost:8765
```
Вне Telegram приложение работает на localStorage (данные только в этом браузере).

## Деплой и подключение к боту
1. **Хостинг (нужен HTTPS).** Залить папку на GitHub Pages / Vercel / Netlify.
   Получится адрес вида `https://<твой>.github.io/kkal/`.
2. **Бот в @BotFather:** `/newbot` (или взять существующий) → получить токен.
3. **Mini App:** в @BotFather `/newapp` → выбрать бота → указать **Web App URL**
   (адрес из п.1) → задать имя/иконку. Либо `/setmenubutton` → тот же URL.
4. Открыть бота → кнопка меню/Mini App → приложение запустится внутри Telegram,
   данные пойдут в CloudStorage и синхронизируются между устройствами.

## Заметки
- CloudStorage: ≤ 1024 ключей, значение ≤ 4096 байт. Данные разложены по ключам
  `food:<id>`, `recipe:<id>`, `day:<дата>`, `settings` — для личного использования
  лимитов хватает с запасом.
